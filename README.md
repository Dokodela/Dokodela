## 🧭 About Me

I'm a Computer Science student building my path toward AI engineering. I like understanding systems from the ground up: how data moves across a network, how an operating system schedules work, and how the math behind a model turns numbers into decisions.

## 🔭 What I'm Exploring

| Focus | What I'm digging into |
|---|---|
| 🧠 Artificial Intelligence | Machine learning fundamentals and neural networks |
| 🌐 Computer Networks | Protocols, routing, and how the internet really works |
| 💻 Operating Systems | Processes, memory management, and scheduling |
| 🏗️ Computer Architecture | How CPUs, memory, and instruction sets fit together |
| 🗄️ Database Systems | Data modelling, queries, and cloud databases |
| ➗ Calculus | Limits, derivatives, and integrals |
| 📈 Advanced Calculus | Rigorous multivariable analysis and convergence |
| 🔢 Mathematical Analysis | The theory that makes algorithms trustworthy |
| 🧩 Abstract Algebra | Groups, rings, and fields |
| 🔣 Set Theory | The logical foundation underneath all of mathematics |
