## 🧭 About Me

I'm a Computer Science student building my path toward AI engineering. I like understanding systems from the ground up: how data moves across a network, how an operating system schedules work, and how the math behind a model turns numbers into decisions.

| 🗄️ Database Systems | Data modelling, queries, and cloud databases |
| ➗ Mathematical Analysis | The theory that makes algorithms trustworthy |
